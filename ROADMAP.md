# Roadmap

ClawQueue v0.1.0 starts clean.

The public roadmap is tracked in GitHub issues and projects rather than this file.
Use this document as a pointer, not a promise list.

Direction:

- GitHub stays the durable work contract.
- Local machines run the workers.
- Policy stays inspectable in markdown/config.
- Output stays reviewable in GitHub.
